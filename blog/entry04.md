# How I Tinkered With Aframe:

I used the default code provided in the Aframe webiste; showcasing a basic shapes in random postions as shown:

```
<html>
  <head>
    <script src="https://aframe.io/releases/1.7.1/aframe.min.js"></script>
  </head>
  <body>
    <a-scene>
      <a-box position="-1 0.5 -3" rotation="0 45 0" color="#4CC3D9"></a-box>
      <a-sphere position="0 1.25 -5" radius="1.25" color="#EF2D5E"></a-sphere>
      <a-cylinder position="1 0.75 -3" radius="0.5" height="1.5" color="#FFC65D"></a-cylinder>
      <a-plane position="0 0 -4" rotation="-90 0 0" width="4" height="4" color="#7BC8A4"></a-plane>
      <a-sky color="#ECECEC"></a-sky>
    </a-scene>
  </body>
</html>
```
#
## Example 1:

With this code, I decided to test out different ways of changing the color and also the positions/rotation.

```<a-sphere position="0 1.25 -5" radius="1.25" color="#EF2D5E"></a-sphere>```

|

|

V

```<a-sphere position="-1 3.5 -3" rotation="0 45 0" color="#FF8A9D"></a-sphere>```

This change in the code showcases how I was able to chnage the rotation of the sphere and also the color from a bright coral/red into a more calm warm shade of pink.
#

## Example 2:

Another example was when I realized that you are also able to change the color of the sky:

``` <a-sky color="#ECECEC"></a-sky>```

|

|

V

``` <a-sky color="#87CEEB"></a-sky>```

This color code changed the sky from being a white/light gray into becoming a sky blue shade. I was able to do this simply by researching color codes available and understanding what they were going to turn the certain shape/object into.

#

## Example 3:

After finding all this out, I decided to try and create a easy shape; of which I thought of making a ice cream scoop/cone.
```
<!-- Sphere representing the "ice cream scoop" -->
  <a-sphere position="0 2.75 -5" radius="1.25" color="#EF2D5E"></a-sphere>
  
  <!-- Cone representing the "cone" part -->
  <a-cone position="0 0.75 -5" radius-bottom="1.25" radius-top="0" height="2" color="#D2691E"></a-cone>

```
This allowed me to use random shapes like a cone and a sphere together and create a whole new object ("ice cream").
